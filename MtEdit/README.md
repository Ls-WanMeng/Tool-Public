# MtEdit · 文本格式编辑器（排版工作台）

一个**纯前端、零依赖、单文件即可运行**的 BBCode 论坛帖子排版工具。把原始内容写成 BBCode，左侧实时校样、一键复制成品，帮你把论坛帖子排成一张干净的版面。

> 配套 AI 技能定义在 [`SKILL.md`](./SKILL.md)：把一段原始文本自动排成好读、有重点的 BBCode 帖子。

---

## 特性

- **所见即所得校样**：左边写 BBCode，右边实时渲染成 HTML 预览（BBCode → HTML 实时转换）。
- **可视化工具体盘**：字号、字体、对齐一键应用；文字色 / 底色色卡，并记住最近使用的颜色。
- **彩虹文字生成器**：逐字上色，一键插入一串彩色标签，做出渐变文字效果。
- **常用标签面板**：粗体、斜体、下划线、删除线、链接、图片、代码、隐藏、引用、列表、表格、音频，点一下即插入。
- **复制 / 导出**：
  - 复制 BBCode 成品到剪贴板；
  - `Skill` 菜单可复制「文字 + SKILL」或直接下载为 `.txt` 文件。
- **自动保存**：内容只保存在本机（`localStorage`），刷新不丢。
- **撤销 / 重做**：`Ctrl` / `⌘` + `Z` 撤销，加 `Shift` 重做；并提供浮动按钮。
- **深色模式**：右上角一键切换，偏好也会被记住。
- **标签手册**：内置常用语法与效果对照，折叠展开即查即用。
- **图片防盗链兜底**：图床加载失败时自动改用百度图片中转。

## 快速开始

无需安装、无需构建，直接打开即可：

```bash
# 方式一：双击 index.html，用浏览器打开
# 方式二：本地起一个静态服务（推荐，避免个别浏览器限制）
python -m http.server 8080
# 然后访问 http://localhost:8080
```

| 文件 | 作用 |
|------|------|
| `index.html` | 页面结构与界面 |
| `123.css` | 样式（杂志风排版视觉） |
| `123.js` | 全部交互逻辑（BBCode 解析、校样、复制、撤销重做等） |
| `SKILL.md` | 配套 AI 排版技能定义 |

> 三个文件需放在同一目录。`123.css` 与 `123.js` 通过 `?v=24` 版本号缓存控制，更新文件时记得同步版本号。

## 基本用法

1. 在左侧「正文」编辑区写入内容，支持 BBCode，例如：
   ```
   [b]粗体[/b]、[color=Red]红字[/color]、[size=5]大标题[/size]
   [align=center]居中文字[/align]
   [url=https://example.com]示例链接[/url]
   ```
2. 右侧「校样」区实时显示排版效果。
3. 用工具盘或浮动标签面板快速插入标签，无需手敲。
4. 点「复制 BBCode」把成品贴到论坛；需要 AI 美化时用 `Skill` 菜单。
5. 内容会自动保存；需要重来点「清空内容」。

支持的 BBCode 标签与限制详见 [`SKILL.md`](./SKILL.md) 的「硬性边界」一节（行内 / 块级 / 媒体链接标签范围、size 1‑7、align 取值等）。
